Review a team’s same-day clock times, resolve the held rows, and download checked hours.

1. Add the CSV export

One employee and date per row, with one or two work segments. Keep the original file for reference.

Load the example to see a missing punch and a repeated day.

2. Match the columns

Times can use 24-hour H:MM or 12-hour AM/PM. An unused second segment can be blank or zero in both fields. This review covers same-day segments. Overnight shifts and clock-change days need separate review.

3. Resolve and download

Edit a clock time to correct it. Excluding a row requires a reason. The review log records corrections, exclusions and held rows.
